# Roadmap

## 已完成（0.3.0）
- 七个工具：路径记录/检索、任务日志、能力核对、素材登记。
- 一条龙：接到新任务自动查旧路径，多步任务自动建日志，全程不询问用户。
- 写入前剥离标签残渣；日志时间用本地时区；能力核对只报命中/缺失。

## 待办

### 1. 能力核对覆盖内置技能
`check_capability` 只扫 `~/.dsh/skills` 和各 profile 的 bundles，DSH 内置技能不在其中，会把「装了 office-xlsx 却报没找到 excel」。需要把内置技能目录也纳入扫描。

### 2. 检索结果更省屏幕
`recall_thoughts` 不带关键词时返回最近 5 条**全文**，问一句「存了什么」会刷屏。改成每条一行摘要，需要详细内容时再按 id 取。

### 3. 自动检索更可靠
现在的「接到新任务先查旧路径」靠提示词约束，模型偶尔会漏查。可选方向：在工具返回值里带上「本次未检索路径库」的提醒，或在会话开始事件里自动注入最近的相关路径。
